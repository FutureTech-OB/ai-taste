# Human Ratings

This directory contains de-identified management human-rating files used for the paper.

| File | Use |
|---|---|
| `expert_ratings_deidentified.jsonl` | Article-level expert rating summary |
| `student_ratings_deidentified.jsonl` | Article-level junior-researcher rating summary |
| `reproducibility/expert_reproducibility.jsonl` | De-identified expert-vote file used to recompute majority-vote analyses |
| `reproducibility/expert_reproducibility_filtered.jsonl` | Expert filtering sensitivity file |
| `reproducibility/student_reproducibility.jsonl` | De-identified junior-vote file used for filtering sensitivity |
| `reproducibility/student_reproducibility_filtered.jsonl` | Filtered junior-vote file used for primary junior benchmark analyses |

Rater identifiers are release-stable pseudonyms and are not names, email addresses, institutions, IP addresses, or survey-system identifiers.
