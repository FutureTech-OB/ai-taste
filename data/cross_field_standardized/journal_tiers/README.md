# Journal-Tier Mappings

This directory contains journal-to-tier mappings for the six additional non-management fields with released lookup files.

| File | Field |
|---|---|
| `business_finance_final.md` | Business and finance |
| `communication_final.md` | Communication |
| `political_science_final.md` | Political science |
| `psychology_final.md` | Psychology, multidisciplinary |
| `public_administration_final.md` | Public administration |
| `sociology_final.md` | Sociology |
| `journal_rank_lookup.csv` | Machine-readable lookup table across the six additional fields |

Management and economics mappings are included in the supplementary table CSV files.

The unified rank labels are `exceptional`, `strong`, `fair`, and `limited`.
