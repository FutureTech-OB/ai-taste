# Supplementary Tables

This directory contains machine-readable CSV versions of Supplementary Tables ST1-ST24 plus ST2b, the current GPT-5.5 all-field audit table.

Use:

```bash
python3 scripts/reproduce_tables.py
```

to copy the released table set to `reproduced/tables/` and write checksums.

`TABLE_INDEX.csv` lists each table identifier, filename, and description.
