# Availability

## Public Repositories

Reproducibility package:

https://github.com/FutureTech-OB/ai-taste

Training resources, including training code, training-data preparation
documentation, and training/validation entrypoints:

https://github.com/FutureTech-OB/AI-Taste-Training

Open model weights and training-data files:

https://huggingface.co/collections/K1mG0ng/ai-taste-scientific

## Suggested Availability Text

Data, figure assets, provenance files, validation scripts, and deterministic
reproduction scripts are available at
`https://github.com/FutureTech-OB/ai-taste`. Training code, training-data
preparation documentation, and training/validation entrypoints are maintained
at `https://github.com/FutureTech-OB/AI-Taste-Training`. Open model weights
and training-data files are available from
`https://huggingface.co/collections/K1mG0ng/ai-taste-scientific`.

## Scope

The reproducibility package is the primary public release for data, tables,
figure assets, and validation scripts. The training repository is separate for
training/validation code, while large training-data files and open-weight
checkpoints are hosted in the Hugging Face collection so they can be maintained
without expanding the reproducibility package.
