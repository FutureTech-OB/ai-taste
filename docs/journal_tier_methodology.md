# Journal-Tier Methodology

Journal tiers use the unified four-label evaluation scheme:

- `exceptional`
- `strong`
- `fair`
- `limited`

Management and economics mappings are released in the supplementary table CSV files. Six additional non-management field mappings are released in `data/cross_field_standardized/journal_tiers/` and in ST5-ST10.

The lookup files document the label mappings used in the held-out evaluation surfaces. They do not include decision-history notes.
